# Skills de ADMOSA

Colección de guías para el trabajo con Git, GitHub y Salesforce.

| Skill | Cuándo usarla |
| --- | --- |
| [Git y GitHub](salesforce/git-workflow/SKILL.md) | Ramas, revisión del historial y cambios, commits y pull requests. |
| [Arquitectura Salesforce](salesforce/salesforce-solution-architect/SKILL.md) | Análisis de requisitos, decisiones de diseño y planificación técnica. |
| [Desarrollo Salesforce](salesforce/salesforce-development/SKILL.md) | Implementación, pruebas, validación y despliegue de cambios en Salesforce. |

Para una mejora nueva, usar la rama `feature/<nombre>` y la carpeta `feature/<nombre>/` en la raíz del proyecto. Usar el mismo nombre en ambas, por ejemplo `mejoras-sv`. Guardar la documentación nueva en `feature/<nombre>/documentacion/`. Para mejoras existentes, consultar sus archivos en la ubicación vigente.
